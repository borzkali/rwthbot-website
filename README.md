# RWTH Bot – Projektwebsite

Statische Informationswebsite für das private Desktop-Projekt RWTH Bot.

GitHub Pages: https://borzkali.github.io/rwthbot-website/

- `index.html`: Projekt und Kontakt
- `datenschutz.html`: Datenverarbeitung und Hosting
- `nutzung.html`: Nutzungshinweise
- `style.css`: lokales Stylesheet, keine externen Assets oder Skripte

Die Website enthält keinen App-Quellcode, keine Zugangsdaten und keine Nutzerdaten. Angaben zum lokalen App-Ablauf beruhen auf der Beschreibung des Projektbetreibers.
